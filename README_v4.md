## 📋 What's Included

This package contains **9 professional tools** for TVET training and education management:

### 🛠️ Available Tools:

#### Local Tools (Included in Package):

1. **📋 Workshop Agenda Manager**
   - Create and manage professional workshop schedules
   - Export to DOCX with professional formatting
   - Multi-day support with activity tracking

2. **💰 Training Cost Calculator**
   - Calculate comprehensive training costs
   - Multi-currency support
   - Export to PDF and Excel

3. **🌍 National Qualification Framework**
   - Interactive world map of NQF frameworks
   - Search by country
   - Zoom and pan controls

4. **💼 LinkedIn Post Editor**
   - Format professional LinkedIn posts
   - Unicode text styles (bold, italic, strikethrough)
   - Emoji integration

5. **📊 DACUM Chart Generator**
   - Develop curriculum charts for occupations
   - Organize duties and tasks
   - Export to PDF and DOCX

#### External Tools (Hosted on GitHub Pages):

6. **🔗 Link to QR Converter**
   - Convert URLs and text to QR codes
   - Download high-quality QR codes
   - Instant generation

7. **📝 Result Based Project Proposal Tool**
   - Create RBM project proposals
   - Logical framework development
   - Indicators and monitoring plans

8. **📚 Training Resources Management**
   - Organize training materials
   - Central resource repository
   - Efficient documentation management

9. **🎥 Screen Recorder**
   - Record screen and webcam
   - Create training videos
   - Tutorial creation tool

## 💡 How to Use

### Online (Recommended):
1. Visit the [Live Demo](https://yourusername.github.io/tvet-engineering-tools/MASTER_TVET_Engineering_Tools.html)
2. Click on any tool to open it
3. Work within the tool interface
4. Press **ESC** or click "Back to Tools" to return

### Offline (Local Tools Only):
1. Download or clone this repository
2. Open `MASTER_TVET_Engineering_Tools.html` in your browser
3. Local tools (1-5) work without internet
4. External tools (6-9) require internet connection
