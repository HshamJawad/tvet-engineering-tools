Workshop Agenda Manager
📚 Quick User Guide ▶

📋 Basic Workflow:

  1. Workshop Details: Fill in title, dates, location, and choose type (face-to-face or online)
  2. Workshop Details: Fill in title, dates, location, and choose type (face-to-face or online)
  3. Registration Link: Add registration URL for online workshops (auto-included in LinkedIn posts)
  4. Contact Information: Add facilitator name, phone, and email (optional)
  5. Objectives & Outcomes: Add your learning goals
  6. Create Days: Add workshop days and sessions
  7. Smart Time Calculator - How It Works:
    • First Session: Enter "From" time (e.g., 09:00) + Duration (e.g., 60 min) → "To" time auto-calculates (10:00)
    • Next Sessions: Just enter Duration → Start AND end times auto-calculate from previous session!
    • Chain Reaction: Change any duration → All following sessions update instantly
    • Manual Override: You can still edit times manually if needed
    • Keyboard Tip: Click into a time field, then use the ↑ / ↓ arrow keys to adjust the selected segment — hour, minute, or AM/PM — without opening the picker
  8. Export & Share: Save as Word document, JSON file, or generate LinkedIn posts

💡 Pro Tips:

  • Location Details: Location (city-building), Address (street), Venue (specific hall/room)
  • Contact Info: Add facilitator details for professional communication
  • Start with Day 1: Set your first session start time, then just use durations
  • Language Switch: Toggle EN/AR anytime - full Arabic support with Iraqi month names

🎯 Quick Actions:

  • + Add Session: Regular workshop session
  • 📤 Share: Email, WhatsApp, or LinkedIn post generator
  • 💼 LinkedIn: Auto-generate professional posts for promotion
  • 📄 Export Word: Download formatted document
